# HomeFleet v0.5.3 — run the daemon outside packaged apps on Windows

**A documentation release, and the first one delivered by fleet push.** It records a Windows pitfall found on the rig: a `homefleetd` started from a terminal inside a packaged (MSIX) desktop app, such as the Claude desktop app, gets a private copy of `%LOCALAPPDATA%` and is killed whenever that app closes or updates. There are no code changes beyond the version.

Real-hardware status: this release exists to be pushed. The rig proof is `homefleet fleet upgrade` on the laptop rolling v0.5.3 to the tower and then to the laptop itself, plus a refusal check against a peer with remote upgrades off. It necessarily follows publishing and is recorded in the next devlog. The pitfall itself was found on the rig: the laptop's daemon twice vanished without a log line, and its identity turned out to live in the Claude app's private `LocalCache`.

## What's new
- **Windows: start `homefleetd` outside packaged apps.** The README Install section and the configuration reference's "Data directory" section explain the symptom: a daemon that disappears when the app closes, or a fresh identity with no pairings when started normally later. The fix is to run the daemon from the Task Scheduler task `homefleet setup` prints, or from your own terminal. If a daemon already lived inside a package, copy its private folder (`%LOCALAPPDATA%\Packages\<app>\LocalCache\Local\homefleet`) into `%LOCALAPPDATA%\homefleet` from a process outside the app before starting it normally.

## Known limitations
- **The daemon cannot yet detect that it runs inside a packaged app.** That needs a Windows API Node doesn't expose without a native add-on, so the guidance is documentation only.
- Everything listed for [v0.5.2](v0.5.2.md) still applies: peers need `"upgrade": { "allowRemote": true }` to accept a push, only v0.5.2+ peers accept one, the dashboard trigger and per-boot control token are Phase 4, Windows-first, not on the npm registry.

## Install
On a v0.5.2 fleet, from one node:
```bash
homefleet fleet upgrade
```
On a single v0.5.0+ node:
```bash
homefleet upgrade
```
Fresh install, or from v0.4.0 or older:
```bash
npm i -g https://github.com/Hugodzl/HomeFleet/releases/download/v0.5.3/homefleet-0.5.3.tgz
```
See the [README](https://github.com/Hugodzl/HomeFleet/blob/v0.5.3/README.md#install).
