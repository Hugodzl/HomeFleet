# HomeFleet v0.5.1 — see versions and model status from the CLI

**The first release you install with `homefleet upgrade`.** On a v0.5.0 node, `homefleet upgrade` fetches this release, checks its signature, installs it and restarts the daemon, rolling back if it doesn't come up. It also makes upgrades and models easier to watch from the terminal: `homefleet nodes` shows each peer's version, and both `nodes` and `status` show why a model is or isn't usable.

Real-hardware status: v0.5.1 is the release the rig's first real self-upgrade (0.5.0 → 0.5.1) runs against, so that proof necessarily comes after publishing. It is recorded in the next devlog along with a forced-rollback test on the tower. The CLI changes are covered by unit tests.

## What's new
- **`homefleet nodes` has a VERSION column**, read from each reachable peer's live node info, so you can watch a fleet move from one release to the next without querying the control API.
- **Per-model status in `nodes` and `status`:** each model prints with its startup-probe verdict, e.g. `qwen3.6-35b-a3b (not_served)`. `not_served` means the model server is up but serves a different model id (for llama-server, start it with `--alias <id>`). `unreachable` means the server wasn't answering when the daemon started.
- **`homefleet status` prints the last upgrade:** `lastUpgrade: 0.5.0 → 0.5.1 succeeded at <time>`, or the outcome and reason of a rollback or failure, or `(none)`.

## Known limitations
- **Model status is still probed only at daemon startup.** A model server started after homefleetd stays `unreachable` until the daemon restarts. Re-probing is on the backlog (node lifecycle automation).
- **Nodes on v0.4.0 or older must update by hand** to v0.5.0 or later first (`npm i -g` the tarball below); only v0.5.0+ has `homefleet upgrade`.
- **Local only:** `homefleet upgrade` upgrades the node you run it on; fleet push and a dashboard trigger come later.
- **Not on the npm registry yet**: install from the Release asset URL.
- **Pre-alpha, Windows-first.** Linux runs in CI; macOS is untested.

## Install
On a v0.5.0 node:
```bash
homefleet upgrade
```
Fresh install, or from v0.4.0 or older:
```bash
npm i -g https://github.com/Hugodzl/HomeFleet/releases/download/v0.5.1/homefleet-0.5.1.tgz
```
See the [README](https://github.com/Hugodzl/HomeFleet/blob/v0.5.1/README.md#install).
