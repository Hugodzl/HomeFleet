# HomeFleet v0.1.0 — recon + command delegation over LAN

**Your coding agent, but your other PCs do the heavy lifting.**

HomeFleet's first tagged release. A daemon per machine, paired once Syncthing-style (device ID = cert fingerprint, mTLS, no CA, no accounts); any MCP-capable agent (Claude Code, LM Studio, goose, Cline, ...) gets `list_nodes` / `delegate_task` tools, and the delegated work runs entirely on **local models**, entirely on **your LAN**.

## What v0.1.0 does

- **Recon delegation** — "explore this repo, summarize the architecture" runs on a worker machine's local model (any OpenAI-compatible server: llama.cpp `llama-server`, Ollama, LM Studio) against a git-bundle-synced copy of your repo. No shared remotes, no cloud.
- **Command delegation** — allowlisted commands (test suites, builds) run on any paired machine, output and exit code stream back.
- **LAN auto-discovery** (mDNS + UDP fallback), short-code pairing, live capability-aware node list, job status/streaming, cancellation.
- Windows-first reference setup; cross-platform TypeScript.

## Verified on real hardware

The two-machine reference rig (Ryzen 5600X + RX 6700 XT running Qwen3.6-35B-A3B on llama.cpp/Vulkan; i7-6700HQ + GTX 1060 running Qwen3.5-4B on Ollama/CUDA):

- Recon delegation against this repo: accurate architecture summary from the 35B model in ~105 s end-to-end (12 read-only tool calls, ~22 tok/s generation)
- Command delegation both directions: 29–67 ms worker wall, incremental re-sync 129 ms vs ~6 s cold
- Mid-job cancel, unpaired-node rejection, and the Windows MAX_PATH story — see [devlog 010](https://github.com/Hugodzl/HomeFleet/blob/main/devlog/2026-07-09-m8-rig-bringup.md) and [devlog 011](https://github.com/Hugodzl/HomeFleet/blob/main/devlog/2026-07-09-v01-release-polish.md)

## Install

From source (not yet on npm): Node ≥ 20, pnpm 11, git —

```bash
git clone https://github.com/Hugodzl/HomeFleet.git
cd HomeFleet
pnpm install && pnpm build
node packages/daemon/dist/bin/homefleet.js setup
```

Full walkthrough in the [README](https://github.com/Hugodzl/HomeFleet#quickstart), every config key in the [configuration reference](https://github.com/Hugodzl/HomeFleet/blob/main/docs/reference/configuration.md).

## Known limits (v0.1, by design)

No code-writing delegation, no GUI, no cloud relay, non-Windows platforms untested (code is cross-platform-friendly). 601 tests; everything is testable on a single machine.
