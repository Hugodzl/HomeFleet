# HomeFleet v0.6.3 — a daemon log file, always, and dashboard tooltips

**`homefleetd` now always writes a timestamped log, `homefleetd.log`, in its data directory.** Before this, a daemon started by a scheduled task (no redirect) left no log at all, and the self-updater's `homefleetd.err.log` had no timestamps. On 2026-11-02 the laptop's daemon stopped with no trace, so the cause couldn't be found. The next stop will at least be dated, and if it was a crash, explained.

## What's new
- **`<dataDir>/homefleetd.log`.** Every line the daemon writes to stderr is also appended there, prefixed with an ISO-8601 UTC timestamp, however the daemon was started.
- **Start and exit are recorded.** Each start logs `homefleetd <version> starting, pid <pid>`. Each exit logs `homefleetd: exiting with code <n>`. An uncaught exception or unhandled rejection logs its stack before the process dies. Writes are synchronous, so these survive a crash.
- **Bounded size.** Past 5 MB the file rotates once to `homefleetd.log.1`, which replaces the previous one.

See [Data directory](../reference/configuration.md#data-directory) in the config reference.

### Dashboard tooltips
- **Every header and label explains itself on hover.** That covers the Paired nodes columns (reachable, version and the upgrade badge, models with `ok` / `not_served` / `unreachable`), the This node rows, the job tables, the rollout progress states, the header buttons, and the upgrade dialog's terms. Headers that have an explanation get a dotted underline.

## Known limitations
- A forced kill (Task Manager, `Stop-Process -Force`, `kill -9`) can't be logged. The last timestamped line still dates the stop.
- `homefleetd.err.log` is unchanged: the self-updater still redirects a relaunched daemon's raw stderr there, so its lines also appear, untimestamped, in that file. It's the place to look when the daemon fails before its own code runs.
- Everything listed for [v0.6.2](v0.6.2.md) and earlier still applies.

## Install
On a v0.6.0+ fleet, from the dashboard: **Upgrade all**. Or, from one node:
```bash
homefleet fleet upgrade
```
On a single v0.5.0+ node:
```bash
homefleet upgrade
```
Fresh install, or from v0.4.0 or older:
```bash
npm i -g https://github.com/Hugodzl/HomeFleet/releases/download/v0.6.3/homefleet-0.6.3.tgz
```
See the [README](https://github.com/Hugodzl/HomeFleet/blob/v0.6.3/README.md#install).
