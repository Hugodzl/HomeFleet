# HomeFleet v0.3.1 — install polish

**Two rough edges from the first packaged install, fixed.** v0.3.1 is a small follow-up to v0.3.0: both issues were found by running the installed release on the reference rig, not from a checkout.

## What's fixed
- **`homefleet setup` no longer tells packaged users to run `pnpm build`.** The autostart hint used to appear unconditionally; it is now printed only when the resolved `homefleetd.js` is actually missing, which only happens when running from source.
- **Daemon logs read correctly in Windows PowerShell.** `homefleetd`'s stderr lines used typographic punctuation (`—`, `…`) that Windows PowerShell 5.1 shows garbled (`â€"`, `â€¦`) when reading a redirected log file with `Get-Content`. Log lines now use plain ASCII punctuation; other characters, such as accented letters in paths, are untouched.
- **Release notes live in the repo.** Each Release's title and notes now come from `docs/releases/<tag>.md`, and the release workflow refuses a tag without one.
- **Deflaked a UDP discovery test** that could fail under a loaded parallel test run.

## Known limitations
- **Not on the npm registry yet** — install from the Release asset URL.
- **Pre-alpha, Windows-first.** Linux runs in CI; macOS is untested.

## Install
```bash
npm i -g https://github.com/Hugodzl/HomeFleet/releases/download/v0.3.1/homefleet-0.3.1.tgz
```
Upgrading from 0.3.0 is the same command; restart `homefleetd` afterwards. See the [README](https://github.com/Hugodzl/HomeFleet/blob/v0.3.1/README.md#install).
