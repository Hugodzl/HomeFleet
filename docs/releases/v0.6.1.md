# HomeFleet v0.6.1 — clearer dashboard upgrade headings

**Two dashboard labels now say what they mean.** A small follow-up to v0.6.0, and the release used to prove upgrading from the dashboard on real hardware.

Real-hardware status: v0.6.1 is pushed to the rig with **Upgrade all** on the laptop's dashboard, from two nodes on v0.6.0. That run follows publishing; see the devlog.

## What's new
- **"Last rollout".** The daemon also serves the saved record of a finished rollout, which may be days old. The dashboard now titles it "Last rollout" instead of "Upgrade progress"; a running rollout keeps "Upgrade progress".
- **"Upgrade failed".** When a verified release fails to start (for example, every target is busy), the dialog is titled "Upgrade failed" instead of "Upgrade failed to prepare".

## Known limitations
- Everything listed for [v0.6.0](v0.6.0.md) and earlier still applies.

## Install
On a v0.6.0 fleet, from the dashboard: **Upgrade all**. Or, from one node:
```bash
homefleet fleet upgrade
```
On a single v0.5.0+ node:
```bash
homefleet upgrade
```
Fresh install, or from v0.4.0 or older:
```bash
npm i -g https://github.com/Hugodzl/HomeFleet/releases/download/v0.6.1/homefleet-0.6.1.tgz
```
See the [README](https://github.com/Hugodzl/HomeFleet/blob/v0.6.1/README.md#install).
